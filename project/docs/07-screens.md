# 07 · Screens

14 screens, each captured at two viewports in both themes: 56 full-page PNGs, generated by
`project/scripts/capture_screenshots.py` against the local app.

| Bucket | Viewport | Path |
|---|---|---|
| Desktop | 1440 × 900 | `screenshots/web/light/`, `screenshots/web/dark/` |
| Mobile | 390 × 844 at 2× | `screenshots/mobile/light/`, `screenshots/mobile/dark/` |

**What the captures show.** They were taken on 2026-11-06 against the local database, signed in as
`pro@localiq.in`. The local corpus has only the geo layer and no LLM or OpenWeather key was set,
so air, water, power, rent and infrastructure cards are empty, the narrative is the fixed fallback
text, and the run-cost panel reads `none — served from cache`. The community feed includes posts
written by the pytest suite (author "Pytest Bot").

## Design system

| Item | Value |
|---|---|
| Style | "Achromatic ledger": ink chrome on a pale sage ground (`--background: 242 245 242`), white sheets with a 1 px border, no resting shadow |
| Data hue | one blue, `--data` (`29 95 191` light, `110 162 236` dark), used only for the reader's score and the ledger bars |
| Status hues | emerald, amber and red keep their meaning (better, watch, worse) |
| Palette | `frontend/scripts/gen-palette.js` writes `src/palette.css`; Tailwind colour ramps read those variables. The former brand ramps (indigo, violet, teal, cyan, pink, slate) resolve to ink, so no other hue reaches the chrome |
| Type | Geist for text, Geist Mono for numbers and labels, from Google Fonts |
| Theme | light by default; dark through `next-themes` (class strategy), stored in `localStorage.lq-theme` |
| Icons | Phosphor (`@phosphor-icons/react`) |
| Charts | Recharts, in `Renderers.jsx` and the Compare page |
| Components | plain Tailwind; one Radix popover (citation details) in `components/ui/`; `sonner` for toasts |
| Landing | its own stylesheet, `pages/landing/landing.css`; photos from Wikimedia Commons, credited on the page |

## Regenerating

```bash
# from the repo root, with the backend on :8001 and the frontend on :3000
backend/.venv/bin/python project/scripts/capture_screenshots.py
```

The script logs in as `pro@localiq.in`, reuses (or generates) that user's Indiranagar
family-with-kids report, mints a contribution link and a share link, then captures every screen
with Playwright's Chromium.

**Known gap.** The script does not scroll before a full-page capture. The landing page's sections
fade in when they scroll into view, so its `01-landing.png` files come out with a blank middle. The
four landing captures in this folder were retaken after scrolling the page top to bottom, with the
same viewports, scale and theme setting. Compare and Recommend are captured before running.
