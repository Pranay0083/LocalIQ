## Design system

| Token | Value |
|---|---|
| Theme | Light-first, dark toggle via `next-themes` (`localStorage.lq-theme`) |
| Palette | CSS variables in `frontend/src/palette.css`, consumed by `tailwind.config.js` |
| Display type | Outfit (light weights, tight tracking) |
| Mono / labels | IBM Plex Mono — used for every number, score and overline |
| Accents | Teal for contribution and trust, indigo for AI and premium, amber for warnings, slate for unverified |
| Icons | Phosphor (`@phosphor-icons/react`), duotone weight — no emoji |
| Components | shadcn/ui in `frontend/src/components/ui/`, `sonner` for toasts |
